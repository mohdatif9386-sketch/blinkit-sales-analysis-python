# blinkit-sales-analysis-python
Blinkit Sales Analysis using Python, Pandas, NumPy, Matplotlib and Seaborn.

## Project Overview

This project focuses on analyzing Blinkit's sales data using Python.
The objective is to analyze sales performance, customer satisfaction,
and inventory distribution to identify key business insights and
opportunities for optimization.

## Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Jupyter Notebook

## Key KPIs

- Total Sales
- Average Sales
- Number of Items
- Average Customer Rating

## Analysis Performed

### 1. Total Sales by Fat Content
Analyzed the impact of different fat content categories on total sales
and compared key KPIs such as average sales, number of items, and
average rating.

### 2. Total Sales by Item Type
Analyzed the performance of different item types based on total sales
to identify high-performing product categories.

### 3. Fat Content by Outlet for Total Sales
Compared total sales across different outlets while analyzing the
distribution of fat content.

### 4. Total Sales by Outlet Establishment
Analyzed how outlet establishment year or age affects overall sales
performance.

### 5. Sales by Outlet Size
Analyzed the relationship between outlet size and total sales.

### 6. Sales by Outlet Location
Analyzed sales distribution across different outlet locations.

## Key Insights

## How to Run

1. Clone this repository.
2. Open `blinkit_analysis.ipynb` in Jupyter Notebook or Google Colab.
3. Place the dataset inside the `dataset` folder.
4. Install the required Python libraries.
5. Run the notebook cells sequentially.
